The gene is a shortened teaching version based on the start of the human beta-globin gene (Met then Val-His-Leu-Thr-Pro-Glu-Glu-Lys-Ser-Ala-Val), with one short intron moved near the start and a stop codon added so everything fits on screen. Positions follow beta-globin numbering, which does not count the first Met, so the sickle cell site is Glu 6. UTRs are left out, splice sites are simplified to GU at the start and AG at the end of the intron, and a broken splice site is shown as the intron being kept. Motion is sped up.
